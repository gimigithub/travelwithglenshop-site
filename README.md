# travelwithglenshop-site

Static replacement for travelwithglenshop.com (WordPress/WooCommerce on HostGator).
Affiliate catalog only: no cart, no checkout. Built with `python3 build.py` into `dist/`, deployed by Netlify.

- `raw/` live export from the WordPress site (via the "Export WooCommerce shop data" Action)
- `search_console_paths_16mo.txt` every shop URL Search Console showed in 16 months (Oct 20, 2026)

Do not cancel HostGator or WooCommerce until this site is live and every old URL returns 200, 301 or 410.
